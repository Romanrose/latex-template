# Contributing

欢迎补充真正值得拆解的可视化作品。优先提交有原作链接、作者/机构信息、数据或实现说明的案例。

## 提交前检查

1. 使用 [`templates/item.md`](templates/item.md) 新建 `items/<slug>.md`。
2. 在至少一个 `collections/*.md` 中加入链接，并更新 `CATALOG.md`。
3. 写清楚可观察到的设计技巧，不以“高级”“好看”代替分析。
4. 不上传原作截图、数据集、代码或品牌素材，除非确认许可允许。
5. 写入链接检查日期；遇到付费墙或登录限制，明确标注。

## 推荐字段

- 原作与作者；
- 类型、主题、图表与交互；
- 最值得借鉴的三点；
- 可复刻条件与难度；
- 数据 / 源码开放情况；
- 版权、访问限制与检查日期。
