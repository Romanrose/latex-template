## 收录标准

每个案例至少满足其中两项：

- 有清楚的叙事、比较或探索任务；
- 视觉语言与数据主题相互支撑；
- 可观察到具体的布局、标注、交互或图形方法；
- 提供源码、数据、制作说明，或足以推断实现路径。

本目录只保存原创说明、链接和分析，不转载原作图片、数据或代码。原作的版权与许可归原作者或平台所有。
