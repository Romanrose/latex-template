# Data Sketches

- 原作链接：[datasketch.es](https://www.datasketch.es/)
- 作者 / 机构：Nadieh Bremer、Shirley Wu
- 类型：数据艺术 / 数据叙事
- 标签：`视觉隐喻` `定制图形` `过程记录` `创意编码`
- 链接检查：2026-08-24

## 它解决了什么问题？

通过十二个主题、二十四个项目和制作记录，展示如何从数据收集、草图到代码形成具有作者性的视觉叙事。

## 最值得拆解的 3 点

1. 视觉语言从主题和数据结构中生长出来，不套用通用模板。
2. 项目同时保留艺术性与可解释的数据编码。
3. 制作说明把失败、迭代和技术选择也纳入作品价值。

## 可复刻线索

- 技术栈：多为 Web 创意编码与定制 SVG / Canvas。
- 数据 / 源码：项目页常提供制作说明；逐项目核对。
- 难度：高。
- 注意：从“一个可解释的隐喻”开始，而不是先决定做炫目的形状。
