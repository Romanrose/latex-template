- 原作链接：[Plot Gallery](https://observablehq.com/@observablehq/plot-gallery)
- 作者 / 机构：Observable
- 类型：开源实现 / 图表图库

- 链接检查：2026-08-24

## 它解决了什么问题？

提供简洁、现代的 Web 图表范例，适合从标记、尺度、变换和分面等基础组合出高完成度图表。

## 最值得拆解的 3 点

1. 用细线、直接标注和留白强化编辑设计感。
2. 图表不是固定类型，而是由几何标记和数据变换组合而成。
3. Notebook 可 Fork，便于从可运行示例开始实验。

## 可复刻线索

- 技术栈：Observable Plot / JavaScript，基于 D3 生态。
- 数据 / 源码：示例可浏览和 Fork；逐示例核对许可。
- 难度：低到中。
- 注意：优先学习注释、尺度与边距，避免只复制单一色板。
