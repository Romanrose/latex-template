# Flowmap.blue

- 原作链接：[flowmap.blue](https://flowmap.blue/)
- 作者 / 机构：FlowmapBlue
- 类型：地图 / 流向数据 / 工具
- 标签：`迁徙` `物流` `起终点` `流图`
- 链接检查：2026-08-24

## 它解决了什么问题？

为迁徙、通勤、物流和交易等起终点数据提供专门的流向地图表达与探索路径。

## 最值得拆解的 3 点

1. 先选定地点再看流向，降低密集连线图的阅读难度。
2. 把规模、方向与地理位置分配给不同视觉通道。
3. 适合比较“与谁连接”“流量多大”“流向何处”三类问题。

## 可复刻线索

- 技术栈：Flowmap.blue、GeoJSON / CSV 起终点数据；也有相关 R 生态。
- 数据 / 源码：以项目站点和代码仓库说明为准。
- 难度：中。
- 注意：流线过多时应提供聚合、筛选或地点聚焦。
