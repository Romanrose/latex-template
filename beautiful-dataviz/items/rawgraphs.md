# RAWGraphs

- 原作链接：[RAWGraphs](https://www.rawgraphs.io/)
- 作者 / 机构：RAWGraphs
- 类型：开源工具 / 非常规图表
- 标签：`快速原型` `海报` `非常规图表` `导出 SVG`
- 链接检查：2026-08-24

## 它解决了什么问题？

让非编程用户也能快速试验不常见的图表形式，并导出为可继续编辑的视觉稿。

## 最值得拆解的 3 点

1. 通过字段映射快速测试“这份数据还能怎么画”。
2. 适合从传统柱线图以外寻找海报式或结构式表达。
3. 导出 SVG 后可在设计工具中继续完成字体、标注和版式。

## 可复刻线索

- 技术栈：RAWGraphs；可配合 Figma、Illustrator 或 Inkscape 做后期。
- 数据 / 源码：开源项目；使用前核对许可证。
- 难度：低。
- 注意：非常规图表需额外测试可读性，不能只因新颖而采用。
