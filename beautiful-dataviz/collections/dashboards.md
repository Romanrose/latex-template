# Dashboard

Dashboard 的高级感通常不是深色背景本身，而是克制的层级：一个结论区、少量指标卡、一张承担比较任务的主图，以及只在必要时出现的筛选。

- [Premier League Opponent Profiling](../items/premier-league-opponent-profiling.md) — 体育分析场景下的深色布局与多图协作。
- [Tableau Viz of the Day](../items/tableau-viz-of-the-day.md) — 持续更新的布局与交互灵感入口。
- [McKinsey Vizro](../items/vizro.md) — 商业分析产品的组件和仪表盘结构。

**拆解问题：** 每张卡片是否真的服务决策？去掉一个视图后是否损失关键比较？
